# DR-001 - Brute Force Detection

**Rule ID:** DR-001
**Severity:** High
**Risk Score:** 73
**MITRE ATT&CK:** T1110.001 - Credential Access, Brute Force

## Description
Detects credential brute force attacks by alerting when 
3 or more failed logon attempts occur against a single 
account within the rule time window.

## KQL Query
event.code : "4625"

## Index Pattern
winlogbeat-*

## Schedule
Runs every 5 minutes, look-back 30 minutes

## Response
1. Identify targeted account from alert details
2. Check source IP - internal or external
3. Check for successful logon after failed attempts
4. If locked out confirm 4740 event present
5. Escalate if successful logon confirmed

## Validated
Tested via runas brute force simulation from WIN11-Client
Alert fired successfully
